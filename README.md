      # SQL & PostgreSQL Project

## Overview
This project demonstrates practical SQL skills using PostgreSQL and pgAdmin. It focuses on retrieving, joining, aggregating, and analyzing relational database data.

## Objectives
- Retrieve data using `SELECT` statements.
- Combine related tables using `JOIN`.
- Calculate totals using aggregate functions such as `SUM()`.
- Group and sort results using `GROUP BY` and `ORDER BY`.
- Develop practical database querying skills.

## Technologies Used
- PostgreSQL
- pgAdmin 4
- SQL

## Queries and Results

### 1. Product Categories and Prices
Retrieve product names, category names, and prices by joining the products and categories tables.

### 2. Total Stock by Product
Calculate total stock quantities for each product using the inventory data.

## How to Run
1. Open PostgreSQL using pgAdmin 4.
2. Connect to your PostgreSQL database.
3. Open the SQL Query Tool.
4. Execute the queries from `queries.sql`.
5. Review the output tables generated by each query.

## Learning Outcomes
This project helped develop practical experience in relational database querying, table joins, aggregation, and data retrieval.
